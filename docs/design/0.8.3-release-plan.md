# MEX 0.8.3 release preparation

Release branch: `codex/release-0.8.3`, based on main
`490ffe5017c6f1abc4f943931f5a683a04b25df7`.
Preparation started September 27, 2026. This branch prepares an unpublished
release dated September 28, 2026. The maintainer will publish after merge.

## Scope and version

The last GitHub and npm release is 0.8.2, published September 13, 2026, at
`91e8a52cc6fba9843c10480ff8e05703377663b8`. The base contains 136 subsequent
commits and 23 merged PRs. GitHub and npm reported the same release commit.

The maintainer explicitly selected 0.8.3. The optional public heartbeat field
and new grounding issue codes are documented as additive changes, with a
release-specific exception to the usual minor-version policy for public fields.
No general versioning rule is changed.

Preparation updates package/lockfile versions, capability goldens, release
notes, changelog attribution, installation examples, compatibility guidance,
and the framework support reference. Translated READMEs retain their explicit
older-narrative notice while updating version pins and the graph upgrade warning.
Existing Discord artwork changes in the original checkout are outside this work.

The release includes incremental refresh, targeted-read performance, grounding
and identity fixes, FastAPI/Flask/NestJS routes, Python dependency checking,
coverage diagnostics, export, Markdown timelines, heartbeat fixes, and skill
discoverability. See the changelog for bounded behavior and accepted costs.

## Upgrade requirements

Keep the existing graph, run `mex graph refresh`, then `mex sync`, review
grounding changes, and commit the scaffold through Git. The first refresh is a
full extraction using `typescript-5.9-v5`; affected TypeScript IDs can change.
Fresh clones and rebuilds without the old graph rely on committed fingerprints
and may need manual re-grounding. Rebuild the Wiki index when scaffold changes
make it stale. Keep MEX-managed and standalone skill installation separate.
