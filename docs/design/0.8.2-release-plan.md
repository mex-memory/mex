# MEX 0.8.2 setup release

Implementation branch: `codex/0.8.2-hub-setup`. This document describes the branch changes; the release is not published.

## Accepted scope

- Browser setup is the default for `mex setup`; bare `mex` opens Hub or setup. `setup --cli`, `tui`, and the read-only `setup --dry-run` keep terminal access. Browser flags and explicit/saved mode selection are preserved.
- The same scaffold, integration, identity, scan, Graph, population, and Wiki finalization phases remain in use. Agent failures retain the real manual prompt. Integration notes appear as advisory guidance.
- Exact Git review and explicit local commit remain required. After committing, show a completion guide; **Open Hub** performs promotion. Failed opening cannot repeat the successful commit. The existing Hub tour remains separate.
- Offer optional global installation at the running package version, with verification, bounded subprocess ownership, progress, retry, copy, and skip. No automatic installation or privilege escalation.
- Offer optional email/name contact using the existing Web3Forms service. Email is required only for submitting, name is optional. Store only submitted/skipped markers under the user's global `.mex/setup/`, and share that preference with Overview. No contact data goes into the repo or telemetry.
- Update commands, README translations, setup template/diagram, privacy guidance, package metadata, capability goldens, and release notes for 0.8.2.

The fresh-project interview remains deferred. No PostHog contact profiles or new tour are introduced.
