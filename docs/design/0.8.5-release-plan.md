## Compatibility verified against source

- Package-root API source and runtime behavior are unchanged by preparation.
- Graph schema remains v4; Wiki index remains v5. No Wiki schema migration is
  introduced for users already on 0.8.4.
- TypeScript extractor changes from `typescript-5.9-v6` to
  `typescript-5.9-v7`; the combined corpus identity changes accordingly.
  Resolver `compiler-first-v3` and extraction cache format 4 are unchanged.
  First refresh rebuilds the graph; keep the old graph for identity mapping,
  then review affected links with check/sync.
- Graph JSONL remains protocol v3 with the read-output changes already merged
  into main, including removal of `sourceBackedNodes`. Those changes are named
  explicitly in the changelog and compatibility guide.
- Existing projects must run `mex skills sync --dry-run`, review conflicts,
  then `mex skills sync` and start a fresh session to receive `mex-statechart`.
  Package upgrades alone do not update project skill copies.
- Whole-team `mh2:` support still requires 0.8.4 or newer. Older upgrade and
  identity-migration guidance remains in the compatibility guide.
