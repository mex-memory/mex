## Project knowledge (MEX)
- This repository keeps curated, code-linked knowledge in `.mex/`. The entries relevant to your work are shown to you automatically as "MEX knowledge": when the task starts, when you open a source file, and when you edit one. Use them to orient; they say how the code works and where to look.
- An entry marked ⚠ describes code that changed after it was written: check the code before relying on it, and say so if the entry is wrong.
- Need more? `mex wiki query "<two or three words>"`, then `mex wiki show <id>` for one entry's text. This is cheaper than opening `.mex` files, which are mostly metadata.
- If your code change makes an entry false, rewrite that entry's prose at the `.mex` line shown with it; do not search `.mex` for entries, the affected ones are listed when you edit code. Never edit `<!-- mex:entity -->` blocks, ids or fingerprints: MEX re-records code links itself when you finish.
